Nạp dữ liệu

Dữ liệu chỉ nằm trong trình duyệt của bạn, không gửi đi đâu.

1. Dán từ Google Sheets / Excel

Chọn vùng dữ liệu kèm dòng tiêu đề → Ctrl C → dán vào đây.

2. Hoặc tải file

Hỗ trợ .csv, .tsv, .xlsx, .xls

3. Hoặc link Google Sheets đã publish

Trong Sheets: Tệp → Chia sẻ → Xuất bản lên web → CSV, rồi dán link vào đây. Link /htmlview hay /edit thường bị trình duyệt chặn (CORS).
